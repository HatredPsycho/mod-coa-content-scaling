title: The CoALFGMode addon sets how the Dungeon Finder forms your group
---
A row above the Dungeon Finder's queue button chooses matchmaking, bot fill or an immediate start with the current group, and the
challenge size the bosses are scaled for. It changes the same per-character settings as `.lfgmode` and `.lfgchallenge`,
which the server now also answers through addon messages.
